# Student Record Table

A simple **Student Record Table** created using **HTML and CSS**.

## About

This project displays student details in a structured table format.

The table contains:

* Roll Number
* Name
* Branch
* CGPA
* Total number of students

## Technologies Used

* HTML5
* CSS3

## HTML Concepts Used

* `<table>`
* `<thead>`
* `<tbody>`
* `<tfoot>`
* `<tr>`
* `<th>`
* `<td>`
* `colspan`

## Features

* Simple and clean table design
* Student information displayed in rows and columns
* Table header and footer
* Basic CSS border styling
* Uses `colspan` to merge table columns
